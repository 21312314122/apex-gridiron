# Apex Gridiron

Dynasty football manager + playable Retro Bowl-style game.

## Play
Open `index.html` (or the ApexGridiron.html from your project folder) in any modern browser.

## Features
- All 32 NFL teams + free agency
- Fan happiness meter
- 10-game season → Playoffs → Super Bowl
- Trade Center
- Career stats
- Local hotseat multiplayer
- Play replays
- **Fixed defender speeds & pocket protection** (no more instant sacks after snap)

## GitHub Pages setup
1. Put the full game HTML in this repo as `index.html`
2. Repo Settings → Pages → Source: Deploy from branch `main`, folder `/ (root)`
